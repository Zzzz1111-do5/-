# 歼-36 与挂载武器参数记录

游戏里的歼-36（沙盒「航空」分类，进攻方）按下面的公开资料建模。官方没有公布歼-36 的任何参数，表里的机体数字都是公开报道中的估算；挂载是按弹舱尺寸做的推测。游戏内的同一份数据在 `js/catalog.js` 的 `WPN` / `AIRDATA` 里，图鉴详情和沙盒条目的「挂载与参数」都读它。

## 机体（公开估算）

| 项目 | 数据 |
| --- | --- |
| 首次曝光 | 2024 年 12 月 26 日在成都被拍到试飞，由一架歼-20S 伴飞；「歼-36」是外界按机头编号 36011 起的称呼 |
| 研制 | 成都飞机工业集团（外界判断） |
| 布局 | 无尾双菱形（改进型三角）翼，翼尖开裂式方向舵，扁平尾喷口 |
| 机长 | 约 22.5–23 米（歼-20 约 21 米） |
| 翼展 | 约 19 米（另有 24 米的估算） |
| 最大起飞重量 | 约 50–60 吨，常见估算 55 吨（歼-20 约 37 吨） |
| 发动机 | 3 台涡扇：两侧各一个进气道，背部一个进气道；型号未公开 |
| 弹舱 | 主弹舱长约 7.6 米；两侧小弹舱是否存在还没有定论 |
| 作战半径 | 估计约 3000 公里 |
| 座舱 | 有并列双座和单座两种说法 |

## 挂载武器

### 霹雳-15（中远程空空导弹）

| 项目 | 数据 |
| --- | --- |
| 制导 | 惯导 + 双向数据链中段修正，末段主动相控阵（AESA）雷达导引头（也有被动模式） |
| 动力 | 双脉冲固体火箭发动机 |
| 弹长 / 弹径 | 约 4.0 米（3996 毫米）/ 203 毫米 |
| 重量 | 约 210 公斤（出口型 PL-15E 公布值） |
| 射程 | 出口型 PL-15E 公布 145 公里；本型各方估计 200–300 公里不等 |
| 速度 | 4 马赫以上（也有 5 马赫的说法，估算） |
| 说明 | 为隐身战斗机内埋弹舱设计，控制舵面截短；歼-20 主弹舱挂 4 枚 |
| 游戏里 | 射程 560（还要飞进本机雷达对目标的锁定距离），间隔 1.2 秒连射 |

### 霹雳-17（超远程空空导弹）

| 项目 | 数据 |
| --- | --- |
| 制导 | 惯导 + 卫星导航 + 数据链中段制导，末段主动相控阵雷达 + 红外复合导引头 |
| 动力 | 双脉冲固体火箭发动机 |
| 弹长 | 约 6 米 |
| 射程 | 估计 300–500 公里（英国皇家联合军种研究所称 400 公里级） |
| 速度 | 4 马赫以上（估算） |
| 说明 | 主要用来打预警机、加油机这类大而笨的高价值目标；平时由歼-16 外挂，歼-20 弹舱放不下；歼-36 内埋两枚属推测；也有人称它霹雳-20 / PL-XX |
| 游戏里 | 射程 900；打运输机、攻击机、直升机命中率 ×1.15，打战斗机 ×0.75；在霹雳-15 射程外或霹雳-15 打光时才用 |

### 雷石-6（滑翔制导炸弹）

| 项目 | 数据 |
| --- | --- |
| 制导 | 惯导 + 卫星导航（改型可选激光、红外或景象匹配末制导） |
| 动力 | 无动力滑翔（2024 年珠海航展展出过加装涡喷发动机的增程方案） |
| 重量 | 有 50 / 100 / 250 / 500 公斤级四种 |
| 射程 | 公开资料没有可靠数字（高空投放可滑翔数十公里） |
| 说明 | 给普通航弹加装弹翼与制导组件的增程精确制导套件 |
| 游戏里 | 投放距离 900，爆炸半径 30；飞得慢，敌防空车、陆基密集阵每次拦截有 35% 把握 |

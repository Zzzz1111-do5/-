# 军事大亨（Roblox 版）0.3

和网页版《暗剑》是两个独立的项目：这里是 Roblox 上的大亨 + 战斗游戏，网页版没有任何改动。

## 玩法

- **大亨**：每人一块基地，踩发光的按钮盖居民楼、工厂、发电厂、银行，每秒自动赚钱；离线最多两小时，按两成算收益。
- **造兵**：25 个兵种，在右边「兵工厂」按页签买（走到军工建筑旁按 E 也会翻到那一页），从工厂开出来停到前面蓝色的部署区，「布阵」里点部队、点位置摆阵型。
  - 步兵（兵营）：步兵班、机枪组、迫击炮组、狙击组、反坦克导弹组（标枪）、单兵防空组（毒刺）
  - 装甲（装甲车厂）：机枪车（M-ATV）、步兵战车、突击炮（PTL-02）、主战坦克、破障车（M1150，皮最厚，敌人优先打它）
  - 防空（防空车间）：防空车、弹炮防空车（PGL-625）、拦截炮（C-RAM，把飞来的炮弹、火箭弹打爆在半空）、爱国者
  - 炮兵（炮兵阵地）：牵引榴弹炮（M777）、自行火炮、重型自行火炮（PzH 2000）、火箭炮
  - 空中（直升机场、空军基地）：武装直升机、运兵直升机（UH-60，每一仗把两个步兵班机降到敌人跟前）、察打无人机（MQ-9，高空绕圈打导弹）、攻击机（A-10）、战斗机（歼-20，只打飞机）、轰炸机（轰-6K，一次扔八颗炸弹）
  - 空军基地盖在基地右边的围墙外面（购买按钮在围墙里靠右），喷气机从跑道上滑跑起飞。
- **你本人上战场**：点「开战」，你的角色传送到己方阵地。物品栏里有枪（步枪；冲锋枪、狙击枪、火箭筒在「武器」里买），按住左键连发、R 换弹；敌人也会打你，阵亡后在基地复活，点「重返战场」回去。
- **亲自驾驶**：战斗中点「开车 / 开飞机」，坐进自己的任何一辆车、直升机、喷气机：
  - 车：WASD 开（手机用摇杆），鼠标瞄准、按住左键开火（手机按「开火」），右键拖动转镜头；
  - 直升机：空格升、C 降；运兵直升机降到最低自动放下步兵；
  - 喷气机：一直往前飞，W / S 加减速，A / D 转弯，空格 / C 升降；轰炸机按一下扔一串炸弹（落在飞机前方）；
  - 右下角显示还要装填几秒；F 下车。
- **兵种克制**：坦克克步兵；直升机、攻击机、反坦克导弹、突击炮克装甲；飞机按飞多高分——步兵、步战车、机枪打得到低空的直升机，高空的无人机、战斗机、轰炸机只有防空车、弹炮、单兵防空、爱国者、战斗机够得着；火炮、迫击炮、轰炸机打扎堆的步兵；拦截炮挡炮弹。每关的敌军开打前就摆在对面（左上角写着），兵种随关卡解锁（到第 22 关会有轰炸机），每十关有一个首领（猛犸重坦）。
- **真人对战**（左边「真人对战」）
  - **排位匹配**：点「开始匹配」，先找同一个服务器里也在匹配的玩家，没有就在全服找对战积分差不多的（等得越久范围越大）；找到后两个人一起传送到一台专门的对战服务器，到齐 5 秒后开打，打完记对战积分（ELO）、发奖金，8 秒后自动送回普通服务器。部队不会损失。
  - **约战**：点名挑战同一个服务器里的玩家，友谊赛，不算积分。
  - **突袭**：打别的玩家存下来的防线（对方不在线也行，按突袭积分匹配差不多强的）；赢了拿战利品、涨积分，对方上线时会看到被突袭了几次。没有合适的真人对手时打 AI 指挥官。
- **长期目标**：军工科技（全军血量、伤害 +10%/级）、指挥部升级（部队上限 4 → 10 → 18 → 30 → 40）、军衔（列兵到上将，头顶显示）、每日奖励（连续登录叠加）、每日任务（三个，领奖励）、全服排行榜（最高关卡、突袭积分、对战积分）、**重生**（打到 20 关、盖了银行后可以重生：从头再来，换永久的收入、战力加成）。
- **指引**：地上一条绿线从脚下连到下一步要去的按钮，按钮头顶一个跳动的箭头，目标不在画面里时屏幕边上有箭头指方向，屏幕上方写着「下一步：……」（新手一路带到第一场仗，之后一直指向买得起的建筑）；要点的界面按钮会闪。左边菜单「指引」可以关。
- **界面能收起**：左上角信息栏、右边兵工厂右上角的「－」点一下收起、「＋」展开；左边菜单最上面「菜单 －」收起整列；「回出生点」一下回到自己基地。
- 一个服务器最多 6 个人（6 块基地并排，各打各的关卡）。

## 打开、测试

1. 装 [Roblox Studio](https://create.roblox.com/)，登录。
2. Studio 里「文件 → 打开」`MilitaryTycoon.rbxlx`。
3. 点「测试 → 开始游戏」。地图、基地、建筑都是开始游戏时由脚本生成的，编辑模式下场景是空的，这是正常的。
4. 想测约战、同服排位：「测试」页签里把玩家数设成 2，点「开始」（本地服务器 + 两个玩家窗口），两个窗口都点「开始匹配」。

没发布之前存档、排行榜、突袭匹配用不了，进游戏会提示「存档没读到」，照样能玩（突袭打 AI 指挥官），只是退出不保存。
要是开始游戏后只看到一片草地、没有小人：服务器脚本出错了——屏幕上会弹出红色提示，或者在 Output（输出）窗口里看红色的字。
**跨服匹配只能在发布后的游戏里用**（Studio 里不能传送）：用两个账号、进两个不同的服务器（或者让朋友帮忙）各自点「开始匹配」。

## 导入原模型（坦克、直升机、飞机……用网页版的真模型）

`models/` 里是从网页版转换好的 24 个模型（.glb，带贴图）：20 个兵种（soldier、ifv、tank、aa、arty、mlrs、heli、transport、drone、attacker、fighter、bomber、jeep、td、breacher、spaag、cram、sam、howitzer、heavyarty）加 4 个步兵组手里的武器（prop_javelin、prop_stinger、prop_mortar、prop_mg）。不导入的话游戏用零件拼的模型，也能玩；只导入一部分也行。

1. Studio「主页 → 导入 3D」（Import 3D），把 `models/` 里的 .glb 都选上导入（设置保持默认，不要勾选合并网格）。
2. 导入后它们出现在 Workspace 里，名字就是上面那些——**不用改名、不用挪**（想整齐的话拖进 ReplicatedStorage → UnitModels 也行）。
3. 开始游戏时脚本自动认出这些模型：摆正方向、缩放到合适的大小、找到炮塔和旋翼的转轴，之后造出来的部队就是原模型，炮塔会转、旋翼会转。输出窗口里会打一行「用上了导入的原模型：……」。

模型都是 Sketchfab 上 CC-BY-4.0 授权的，作者名单在 `models/credits.txt`，游戏里「致谢」按钮也能看到——发布的游戏里请保留。

## 发布到 Roblox

1. 「文件 → 发布到 Roblox」，选「新体验」，填名字、描述，创建。
2. 「主页 → 游戏设置」：
   - **安全 → 打开「允许 Studio 访问 API 服务」**，Studio 里测试也能存档。
   - **地点 → 这个地点 → 最多玩家数设成 6**。
3. 在 [Creator Dashboard](https://create.roblox.com/dashboard/creations) 里把体验设成「公开」。

跨服匹配用到的 MemoryStore、MessagingService、TeleportService（同一个体验里传送）都不用另外开，发布了就能用。
改了脚本以后再「文件 → 发布到 Roblox」一次就更新了。

## 改数值

全部在 `src/Config.lua`（Studio 里是 ReplicatedStorage → Config）：建筑（价格、收入、解锁顺序）、兵种（价格、血量、伤害、射程、速度、射高、克制倍数、第几关开始出现）、关卡敌军（预算、首领）、武器、军衔、重生、每日奖励和任务、突袭、约战、排位对战（`Config.Match`：起始积分、每场涨跌、匹配范围、等对手多久、奖金）、音效（默认没有声音：在工具箱 → 音频里找，把 `rbxassetid://数字` 填进 `Config.Sounds`）。

## 文件

```
src/Config.lua                 共享配置（ReplicatedStorage.Config）
src/Main/init.server.lua       服务器主脚本（ServerScriptService.Main）：进出服务器、状态、操作分发、循环
src/Main/World.lua             地图：地形、六块基地、约战竞技场
src/Main/Store.lua             存档、防线快照、突袭匹配、排行榜、被突袭记录
src/Main/Economy.lua           建筑、收入、指挥部、科技、重生、军衔、每日奖励、每日任务、武器商店
src/Main/Army.lua              平时的部队：生产、阵位、布阵、关卡敌军预览
src/Main/Combat.lua            战斗：关卡、突袭、约战、排位对战；本人上阵、亲自驾驶、机降的步兵、结算
src/Main/Match.lua             真人对战匹配：服内、跨服（MemoryStore 排队、预留对战服务器、MessagingService 通知、传送）；对战服务器的流程
src/Main/Weapons.lua           玩家的枪：发枪、开枪校验、命中、火箭筒
src/Main/Battle.lua            战斗推演：选目标、射高、炮塔、开火、溅射、炮弹、导弹、拦截、喷气机、轰炸、机降
src/Main/Models.lua            模型：零件拼的部队和建筑（含空军基地）、导入原模型的整理、步兵组的武器道具
src/Client/init.client.lua     客户端（StarterPlayerScripts.Client）
src/Client/UI.lua              界面（兵工厂页签、真人对战面板、匹配状态条）
src/Client/Play.lua            操作和镜头：布阵、开车、开飞机、开枪、战斗事件
src/Client/View.lua            部队平滑显示（服务器 20 次 / 秒 → 每帧插值）、炮塔、旋翼、喷气机压坡度
src/Client/Guide.lua           指引：下一步去哪儿（地上的线、头顶的箭头、屏幕边的箭头、提示条、按钮闪）
src/Client/Fx.lua              特效：曳光、炮弹、导弹、炸弹、拦截、爆炸
models/*.glb                   网页版原模型转换的 Roblox 模型
build.mjs                      打包成 MilitaryTycoon.rbxlx
tools/export_models.mjs        从网页版模型重新导出 models/*.glb（tools/view_glb.html 检查）
tools/luacheck.mjs             语法和变量名检查
tools/mock/                    在普通 Lua 里模拟 Roblox，真跑服务器和客户端脚本的测试（test.lua 普通服务器，test_match.lua 对战服务器）
```

改了 `src/` 以后：

```bash
node roblox/tools/luacheck.mjs
```

```bash
python3 roblox/tools/mock/run.py roblox/tools/mock/test.lua 20
```

```bash
node roblox/build.mjs
```

第二条是模拟测试：先单独推演各兵种（射高、拦截炮弹、机降、轰炸、导弹、喷气机、两边 25 个兵种混战），再让机器人玩家进服、盖楼、点界面生产、布阵、开战、拿枪打、开坦克、直升机、战斗机、轰炸机、运兵直升机、突袭、和另一个玩家约战、排位匹配（同服、跨服：模拟别的服务器排队、认领、发消息）、任务、重生、存档读档……全部真跑一遍，再连续玩 20 分钟（模拟时间）打出每场的结果；最后在几台全新的「服务器」里跑：对战服务器的排位流程（两个人到齐开打、对手没来），和 Studio 里没发布的游戏（存档、MemoryStore、传送都用不了，跨服消息的订阅一直不返回——照样能开服、生成小人、盖楼、开战）。需要系统里有 Lua 5.4 运行库（Debian / Ubuntu 的 `liblua5.4-0`）。

# 军事大亨（Roblox 版）0.9.1

和网页版《暗剑》是两个独立的项目：这里是 Roblox 上的大亨 + 战斗游戏，网页版没有任何改动。

## 玩法

- **大亨**：每人一块基地，踩发光的按钮盖居民楼、工厂、发电厂、银行，每秒自动赚钱；离线最多两小时，按两成算收益。
- **造兵**：25 个兵种，在右边「兵工厂」按页签买（走到军工建筑旁按 E 也会翻到那一页），从工厂开出来停到前面蓝色的部署区。
- **布阵**（「布阵」按钮）：镜头自动拉近、框住整个部署区（按屏幕上没被面板挡住的那块取景），部队头顶写着兵种；
  - 点部队选中（Shift 加选、双击选上同兵种的全部、空地上按住拖框多选、下面一排兵种条点一下选一类、「全部」选所有），小兵也好点（按屏幕上离得近的算）；
  - 按住部队拖到别处（选了几个就一起拖、保持队形，地上的绿圈是放下的位置，红圈是出了部署区）；或者选好后点空地放下（几个一起：就地排成一块，步兵在前）；
  - 部队直接摆到位（不再慢慢开过去）；「一键排阵」照兵种排好；「看敌军」看这一关的敌军摆在哪；滚轮朝鼠标缩放、右键转、WASD 平移、空格复位；手机单指拖地图、双指缩放旋转、按住部队拖动。
- **观战**（开战默认）：自动导播——还没接火时从我军背后看过去，接火后框住正在交火的单位、平滑推拉；点任意单位跟着它（追尾镜头，显示血量），「跟随下一个」/ Tab 轮着看自己的部队，
  拖动 / WASD 平移变自由镜头，「自动镜头」/ 空格回自动；鼠标指着单位显示名称、敌我、血量。想亲自打：「操控小人」或者按 1 拿起枪（自动切回自己的小人），「观战镜头」切回来。
  - 步兵（兵营）：步兵班、机枪组、迫击炮组、狙击组、反坦克导弹组（标枪）、单兵防空组（毒刺）
  - 装甲（装甲车厂）：机枪车（M-ATV）、步兵战车、突击炮（PTL-02）、主战坦克、破障车（M1150，皮最厚，敌人优先打它）
  - 防空（防空车间）：防空车、弹炮防空车（PGL-625）、拦截炮（C-RAM，把飞来的炮弹、火箭弹打爆在半空）、爱国者
  - 炮兵（炮兵阵地）：牵引榴弹炮（M777）、自行火炮、重型自行火炮（PzH 2000）、火箭炮
  - 空中（直升机场、空军基地）：武装直升机、运兵直升机（UH-60，每一仗把两个步兵班机降到敌人跟前）、察打无人机（MQ-9，高空绕圈打导弹）、攻击机（A-10）、战斗机（歼-20，只打飞机）、轰炸机（轰-6K，一次扔八颗炸弹）
  - 空军基地盖在基地右边的围墙外面（购买按钮在围墙里靠右），喷气机从跑道上滑跑起飞。
- **你本人上战场**：点「开战」，你的角色传送到己方阵地（镜头先是观战，点「操控小人」或拿起枪接管）。物品栏里有枪（步枪；冲锋枪、狙击枪、火箭筒在「武器」里买），按住左键连发、R 换弹；敌人也会打你，阵亡后在基地复活，点「重返战场」回去。
- **亲自驾驶**：战斗中点「开车 / 开飞机」，坐进自己的任何一辆车、直升机、喷气机：
  - 车：WASD 开（手机用摇杆），鼠标瞄准、按住左键开火（手机按「开火」），右键拖动转镜头；
  - 直升机：空格升、C 降；运兵直升机降到最低自动放下步兵；
  - 喷气机：一直往前飞，W / S 加减速，A / D 转弯，空格 / C 升降；轰炸机按一下扔一串炸弹（落在飞机前方）；
  - 右下角显示还要装填几秒；F 下车。
- **兵种克制**：坦克克步兵；直升机、攻击机、反坦克导弹、突击炮克装甲；飞机按飞多高分——步兵、步战车、机枪打得到低空的直升机，高空的无人机、战斗机、轰炸机只有防空车、弹炮、单兵防空、爱国者、战斗机够得着；火炮、迫击炮、轰炸机打扎堆的步兵；拦截炮挡炮弹。每关的敌军开打前就摆在对面（左上角写着），兵种随关卡解锁（到第 22 关会有轰炸机），每十关有一个首领（猛犸重坦）。
- **真人对战**（左边「真人对战」）
  - **排位匹配**：点「开始匹配」，先找同一个服务器里也在匹配的玩家，没有就在全服找对战积分差不多的（等得越久范围越大）；找到后两个人一起传送到一台专门的对战服务器，到齐 5 秒后开打，打完记对战积分（ELO）、发奖金，8 秒后自动送回普通服务器。部队不会损失。
  - **约战**：点名挑战同一个服务器里的玩家，友谊赛，不算积分。
  - **突袭**：打别的玩家存下来的防线（对方不在线也行，按突袭积分匹配差不多强的）；赢了拿战利品、涨积分，对方上线时会看到被突袭了几次。没有合适的真人对手时打 AI 指挥官。
- **长期目标**：军工科技（全军血量、伤害 +10%/级）、指挥部升级（部队上限 4 → 10 → 18 → 30 → 40）、军衔（列兵到上将，头顶显示）、每日奖励（连续登录叠加）、每日任务（三个，领奖励）、全服排行榜（最高关卡、突袭积分、对战积分）、**重生**（见下）。
- **0.9 新兵种**：空中炮艇（在高空绕圈，105 毫米炮往下砸）、蜂群无人机车（一次放 4 架自杀小无人机撞车）、激光防空（光束打飞机、把炮弹烧爆在半空）、
  电磁炮（一发贯穿一整排）、布雷车（开战在前方撒一片雷，之后再补）、弹道导弹车（每 20 秒打敌人扎堆最密的地方，只有爱国者拦得住）。
- **0.9.1**：密集阵（拦截炮 C-RAM、激光防空，用的都是密集阵模型）改成固定阵地——造好直接架在阵位上，打仗时一步不挪、车身不转、不被挤开，只转炮塔；
  选目标先打射程里的；亲自开它也只能转炮塔、开火。飞机起飞不再一下子全速：喷气机开战时先在原地顺着机头滑跑加速（约 1.6 秒），离地后机头抬起来、
  爬升率一点点加上去，快到巡航高度慢慢改平，速度再加到巡航；直升机先原地拔高十几格再往前飞。平时在基地里：新造的喷气机在空军基地跑道上从静止开始滑跑起飞，
  飞到阵位上空越飞越慢，再像 F-35B 那样慢慢落下、落的时候机头转回朝前；直升机起落也是慢慢加速、慢慢减速。
- **单位技能**：观战时点自己的一个单位跟随它，按「技能」（电脑按 F）：步兵冲锋（跑得快、打得狠）、装甲烟幕（少挨打）、防空全力开火、炮兵急速射、飞机加力冲刺；每个单位各自冷却 25 秒。
- **战况**：从第 4 关起每关一个（首领关、逢 5 的关没有），开打前信息栏写着、开战时播报——大雾（射程短三成，雾气浓）、夜战（天黑、射程短两成）、
  雷区（两军中间埋着中立地雷）、敌机突袭（开打 8 秒轰炸机沿你的阵线扔炸弹）、空降增援（开打 10 秒敌军在中间空降一批步兵和机枪车）。
- **重生和新区域**：基地里（含已经开放的新区域）的建筑全部盖好，左边菜单「重生」就亮了（没盖满时写着进度，比如「重生 23/25」）；最多重生 3 次。
  重生后建筑、现金、关卡、部队、科技清零，换永久加成（每次收入 +50%、部队血量伤害 +10%），再开放一块新区域——基地后墙中间开了南门，门外一条东西向的大路连着三块：
  第 1 次「港口区」（湖边：码头仓库、造船厂、海军司令部，还有伸进湖里的码头）、第 2 次「导弹基地」（推进剂工厂、导弹总装厂、战略导弹营）、第 3 次「航天中心」（卫星工厂、火箭发射台、太空指挥中心）；
  没开放的围着铁丝网、立着「第 n 次重生开放」的牌子。新区域的楼收入高、也能升级，之后的重生要连它们一起盖满。
- **存档**：退出时、关服时存，平时每 30 秒检查一次（这段时间里操作过就存，最多两分钟存一次），打完仗马上存；左下角写着「进度已自动保存（几秒前）」。存档读不到时（Studio 没开 API 访问）左下角是红点，这次的进度不保存。
- **指引**：左上角「当前目标」写着下一步干什么；地上一串往前流动的绿箭头和一条发光的线从脚下连到要去的按钮（补给箱优先），按钮头顶一个跳动、旋转的立体箭头（钱不够时变黄），目标不在画面里时屏幕边上有箭头指方向；要点的界面按钮（兵工厂里买兵、开战、建筑升级）会闪；左边小地图标着能买的按钮和补给箱。左边菜单「指引」可以关。
- **界面能收起**：当前目标、信息栏、兵工厂、小地图右上角的「－」点一下收起、「＋」展开；左边菜单最上面「菜单 －」收起整列；「回出生点」一下回到自己基地。
- **其他**（另一个 AI 在 Studio 里加的）：补给空投、支援技能（迫击炮急袭、战地急救、炮火覆盖、空投援军、空袭、巡航导弹）、建筑升级、地形世界和战区（绿野、沙漠、雪原、城市废墟、火山）与天气、建筑动画、手机紧凑排版、战报和出错红条。
- 一个服务器最多 6 个人（6 块基地并排，各打各的关卡）。

## 你的场景文件为准

你在 Studio 里导入了模型、让另一个 AI 改过之后，**以你存的 .rbxl 为准**（里面有导入的模型，上传后的网格、贴图资源号只在它里面）：
- 拿到新的 .rbxl：`node roblox/tools/rbxl.mjs <文件.rbxl> <输出目录>` 导出实例树和全部脚本，和 `src/` 对比、合并；
- 改好 `src/` 以后写回去：`node roblox/tools/rbxl_patch.mjs <原来的.rbxl> <输出.rbxl>` 只换脚本源码，别的一个字节不动（会再读一遍核对）。
  要加新模块：先在 Studio 里建一个同名的空 ModuleScript、存盘，再写回。
- `node roblox/build.mjs` 生成的 MilitaryTycoon.rbxlx 只有脚本（没有导入的模型），适合从零开始的人。

## 打开、测试

1. 装 [Roblox Studio](https://create.roblox.com/)，登录。
2. Studio 里「文件 → 打开」`MilitaryTycoon.rbxlx`。
3. 点「测试 → 开始游戏」。地图、基地、建筑都是开始游戏时由脚本生成的，编辑模式下场景是空的，这是正常的。
4. 想测约战、同服排位：「测试」页签里把玩家数设成 2，点「开始」（本地服务器 + 两个玩家窗口），两个窗口都点「开始匹配」。

没发布之前存档、排行榜、突袭匹配用不了，进游戏会提示「存档没读到」，照样能玩（突袭打 AI 指挥官），只是退出不保存。
要是开始游戏后只看到一片草地、没有小人：服务器脚本出错了——屏幕上会弹出红色提示，或者在 Output（输出）窗口里看红色的字。
**跨服匹配只能在发布后的游戏里用**（Studio 里不能传送）：用两个账号、进两个不同的服务器（或者让朋友帮忙）各自点「开始匹配」。

## 导入原模型（坦克、直升机、飞机……用网页版的真模型）

`models/` 里是从网页版转换好的 24 个模型（.glb，带贴图）：20 个兵种（soldier、ifv、tank、aa、arty、mlrs、heli、transport、drone、attacker、fighter、bomber、jeep、td、breacher、spaag、cram、sam、howitzer、heavyarty）加 4 个步兵组手里的武器（prop_javelin、prop_stinger、prop_mortar、prop_mg）。不导入的话游戏用零件拼的模型，也能玩；只导入一部分也行。

1. Studio「主页 → 导入 3D」（Import 3D），把 `models/` 里的 .glb 都选上导入（设置保持默认，不要勾选合并网格）。
2. 导入后它们出现在 Workspace 里，名字就是上面那些——**不用改名、不用挪**（想整齐的话拖进 ReplicatedStorage → UnitModels 也行）。
3. 开始游戏时脚本自动认出这些模型：摆正方向、缩放到合适的大小、找到炮塔和旋翼的转轴，之后造出来的部队就是原模型，炮塔会转、旋翼会转。输出窗口里会打一行「用上了导入的原模型：……」。

模型都是 Sketchfab 上 CC-BY-4.0 授权的，作者名单在 `models/credits.txt`，游戏里「致谢」按钮也能看到——发布的游戏里请保留。

## 发布到 Roblox

1. 「文件 → 发布到 Roblox」，选「新体验」，填名字、描述，创建。
2. 「主页 → 游戏设置」：
   - **安全 → 打开「允许 Studio 访问 API 服务」**，Studio 里测试也能存档。
   - **地点 → 这个地点 → 最多玩家数设成 6**。
3. 在 [Creator Dashboard](https://create.roblox.com/dashboard/creations) 里把体验设成「公开」。

跨服匹配用到的 MemoryStore、MessagingService、TeleportService（同一个体验里传送）都不用另外开，发布了就能用。
改了脚本以后再「文件 → 发布到 Roblox」一次就更新了。

## 改数值

全部在 `src/Config.lua`（Studio 里是 ReplicatedStorage → Config）：建筑（价格、收入、解锁顺序）、兵种（价格、血量、伤害、射程、速度、射高、克制倍数、第几关开始出现）、关卡敌军（预算、首领）、武器、军衔、重生、每日奖励和任务、突袭、约战、排位对战（`Config.Match`：起始积分、每场涨跌、匹配范围、等对手多久、奖金）、音效（默认没有声音：在工具箱 → 音频里找，把 `rbxassetid://数字` 填进 `Config.Sounds`）。

## 宣传片

64 秒的 1080p 宣传片，画面全部来自游戏本身：在模拟的 Roblox 里真跑服务器脚本，盖满基地（重生 3 次、开放的新区域都在）、按真实规则打一关，录下场景零件和每个单位每 1/20 秒的位置、开火、爆炸；再用 `models/` 里的原模型逐帧渲染（阴影、天空、雾、色调映射、粒子、光束、字幕卡），配乐和音效全部程序合成（不用外部音频素材）。视频不进仓库。

```bash
TR_LEVEL=27 TR_TECH=2 python3 roblox/tools/mock/run.py roblox/tools/trailer/record.lua /tmp/trailer_rec
```

```bash
NODE_PATH=$(npm root -g) node roblox/tools/trailer/render.mjs /tmp/trailer_rec /tmp/trailer_out
```

第一条录场景（`scene.json`）和战斗（`battle.json`）；`TR_LEVEL` 打第几关、`TR_TECH` 敌军强弱（第 27 关雪原、2 时一场约 50 秒、我方赢）。
第二条依次做：`frames` 逐帧截图（Playwright + 软件渲染，一帧 3–4 秒，全片 1920 帧）、`cues` 不画画面快速走一遍分镜记下音效点、`audio`（`audio.mjs` 合成配乐和音效）、`video`（ffmpeg 合成 `trailer_1080p.mp4`，码率封顶 6 Mbit/s、约 50 MB；另出一份 `trailer_720p.mp4` 约 25 MB）。
后面可以加帧范围和步骤，几个进程分段渲染：`render.mjs <录像> <输出> 0-480 frames`、`480-960 frames`……画完再 `render.mjs <录像> <输出> 0-0 cues,audio,video`。
只看某几帧：`ONLY=300,900,1500` 环境变量。分镜（每个镜头的时间、镜头运动、字幕）在 `timeline.js`，渲染器在 `render.html`。

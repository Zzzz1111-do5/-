## 蓝星纪元

`index.html` 是一个可以独立运行的上帝模拟游戏：用浏览器直接打开就能玩，不需要安装，也不需要联网（联网时会加载更好看的字体）。

你是这颗星球的造物主。七个部落从公元前 3500 年开始定居、扩张、研究科技、打仗、结盟、分裂，你可以随时插手。

**操作**
- 拖动平移地图，滚轮或双指缩放；一直放大能看清每个小人：农夫种地、樵夫伐木、矿工挖矿、工人进厂、学者读书、商人赶路、士兵打仗。
- 放大时时间自动变慢，缩小时历史飞快向前；顶部也可以手动调速。缩到最小会切换成可旋转的地球视图。
- 点击城市或小人查看详情，可以“跟随视角”盯住一个小人。

**造物主工具**
- 文明：播种新部落、建城、赐福、灵感、赐军、煽动独立
- 战争：外交（让任意两国宣战、停战、结盟、吞并）、派兵（指定一座城攻打另一座城）
- 灾难：陨石、瘟疫、地震、火山
- 地形：造陆、沉海、造山、种树

**内容**
- 83 项科技、8 个时代、8 个分支，带完整的科技树，可以把任何科技直接赐给任何国家
- 城市风貌随时代变化：茅草村落、石砌城邦、红砖工业城、玻璃摩天城、未来之城
- 兵种随科技升级：石矛、青铜矛、铁剑、骑士、火枪、步枪、坦克、无人机、机甲
- 工业化、资源枯竭、二氧化碳、全球变暖、海平面上升；卫星、登月、轨道城市、星际方舟
- 18 个成就挑战；世界会自动保存在浏览器里，下次打开继续

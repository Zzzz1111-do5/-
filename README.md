## 蓝星纪元

`index.html` 是一个可以独立运行的文明模拟游戏：用浏览器直接打开就能玩，不需要安装，也不需要联网（联网时会加载更好看的字体）。

七个部落从公元前 3500 年开始定居、扩张、研究科技、打仗、结盟、分裂。开局可以选择两种身份：

- **造物主**：俯瞰众生，挑起或平息任何战争，赐予科技，降下天灾，改写一个国家的意识形态，煽动内战。
- **领袖**：像《钢铁雄心》那样扮演一个文明。推进国策树，选择意识形态道路，亲自定税率、分配预算，在博弈里与各国周旋。胜利目标：统一世界、意识形态胜利或星际胜利。

**操作**
- 拖动平移地图，滚轮或双指缩放；一直放大能看清每个小人。战场上能看到旗手、列阵、弓箭的抛物线、火炮、坦克、海战和被点燃的城市。
- 放大时时间自动变慢，缩小时历史飞快向前；缩到最小会切换成可旋转的地球视图。
- 研究出月球基地后，顶部出现「太阳系」视图，可以点开每颗星球（火星、金星、木卫二、土卫六、系外行星……）看殖民地和行星改造进度。

**每个国家都由一个独立的 AI 执政者运营**
- 每个 AI 每隔几年评估局势（邻国军力、威胁、科技差距、稳定度、霸权国），在扩张、自保、科技立国、工业化、维稳、输出思想、星辰大海、寻求联合、休养生息之间选择战略，并写下决策日志。
- 它会据此宣战、索要城市、求和、结盟、签订互不侵犯条约、提议贸易或合并。
- 财政：GDP 由人口、生产率、工业和出口构成，并乘以企业投资意愿；税收 = 税率 × GDP × 纳税遵从度。税率越高，企业越不愿投资（拉弗曲线）；市场自由度、稳定度和贸易伙伴会提高投资意愿，战争会压低它。
- 预算按意识形态的优先级分配到军费、科研、基建、产业、民生、宣传、航天：法西斯重军费，技术官僚重科研，共产主义高税率、重产业，自由民主重民生和科研。预算会真实地修建铁路（地图上能看到火车）、国立研究院和工厂。
- 意识形态会自我迭代：每 20 年按各自国家的人均产出增长、国力变化和稳定度评比，落后者向最成功的意识形态取经并发生变异，演化出新流派（例如马列主义 → 修正主义 → 市场社会主义）。

**博弈与意识形态**
- 国与国的互动被建模成 2×2 博弈：军备竞赛和贸易是囚徒困境，边境危机是懦夫博弈（双方拥核时变成恐怖平衡），同盟是猎鹿博弈，合并是协调博弈。各国按纳什均衡行动，多重均衡时按互信选择收益占优或风险占优；重复博弈里越有耐心越容易合作。「博弈」页记录每一局的收益矩阵。
- 11 种意识形态（部落、神权、君主、共和、自由民主、共产、法西斯、技术官僚、全球联邦、超人类、蜂巢）会跨越国界传播；民意倒向别的思想时会有选举、政变、革命和内战。被占领的城市会起义，霸权国会招来反制同盟。

**内容**
- 126 项科技、9 个时代、9 个分支；48 项国策（含 6 条互斥的意识形态道路）
- 31 个成就挑战；世界会自动保存在浏览器里，下次打开继续

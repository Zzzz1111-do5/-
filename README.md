## 蓝星纪元

`index.html` 是一个可以独立运行的文明模拟游戏：用浏览器直接打开就能玩，不需要安装，也不需要联网（联网时会加载更好看的字体）。

七个部落从公元前 3500 年开始定居、扩张、研究科技、打仗、结盟、分裂。开局可以选择两种身份：

- **造物主**：俯瞰众生，挑起或平息任何战争，赐予科技，降下天灾，改写一个国家的意识形态，煽动内战。
- **领袖**：像《钢铁雄心》那样扮演一个文明。推进国策树，选择意识形态道路，亲自定税率、分配预算，在博弈里与各国周旋。胜利目标：统一世界、意识形态胜利或星际胜利。

**操作**
- 拖动平移地图，滚轮或双指缩放；一直放大能看清每个小人。战场上能看到旗手、列阵、弓箭的抛物线、火炮、坦克、海战和被点燃的城市。
- 放大时时间自动变慢，缩小时历史飞快向前；缩到最小会切换成可旋转的地球视图。
- 研究出月球基地后，顶部出现「太阳系」视图，可以点开每颗星球（火星、金星、木卫二、土卫六、系外行星……）看殖民地和行星改造进度。
- 左侧「画质」可选 流畅 / 均衡 / 精致 / 极致：影响分辨率、地形细节、建筑阴影、昼夜灯光、水面反光、天气和粒子。默认按设备自动选择，帧率不够时会自动降一档。

**每个国家都由一个独立的 AI 执政者运营**
- 每个 AI 每隔几年评估局势（邻国军力、威胁、科技差距、稳定度、霸权国），在扩张、自保、科技立国、工业化、维稳、输出思想、星辰大海、寻求联合、休养生息之间选择战略，并写下决策日志。
- 它会据此宣战、索要城市、求和、结盟、签订互不侵犯条约、提议贸易或合并。
- 财政：GDP 由人口、生产率、工业和出口构成，并乘以企业投资意愿；税收 = 税率 × GDP × 纳税遵从度。税率越高，企业越不愿投资（拉弗曲线）；市场自由度、稳定度和贸易伙伴会提高投资意愿，战争会压低它。
- 预算按意识形态的优先级分配到军费、科研、基建、产业、民生、宣传、航天：法西斯重军费，技术官僚重科研，共产主义高税率、重产业，自由民主重民生和科研。预算会真实地修建铁路（地图上能看到火车）、国立研究院和工厂。
- 意识形态会自我迭代：每 20 年按各自国家的人均产出增长、国力变化和稳定度评比，落后者向最成功的意识形态取经并发生变异，演化出新流派（例如马列主义 → 修正主义 → 市场社会主义）。

**战争：陆战、海战、空战**（参考《钢铁雄心4》）
- 每场战争最多同时打开三个战区：陆地前线、海上和空中。先争制空权，空军优势会加成地面和海上作战；舰队要护航主力舰、航母压制炮舰、潜艇袭击补给线；陆军按步兵、炮兵、装甲的比例作战，地形、补给、学说都会影响战斗力。
- 74 种兵种模型，放大战场能看到它们：
  - 陆军：从石矛战士、弓箭手、投石机到火枪兵、步兵师、机械化步兵；坦克分轻型、中型、重型、坦克歼击车、主战坦克，再到机甲和反重力坦克；还有自行火炮、火箭炮、防空导弹车。
  - 海军：桨帆战船、风帆战列舰、铁甲舰、鱼雷艇、驱逐舰、轻 / 重巡洋舰、无畏战列舰、航空母舰、潜艇、导弹驱逐舰、核动力超级航母、两栖攻击舰、无人机母舰。
  - 空军：飞艇、双翼机、单翼战斗机、俯冲轰炸机、鱼雷轰炸机、战略轰炸机、喷气式战斗机、武装直升机、预警机、隐身战斗机 / 轰炸机、蜂群无人机、巡航导弹和洲际导弹。
- 军事科技单独研究，和民用科技并行。科技树分成「文明」和「军事」两组共 10 个分页（农业与医学、社会与政治、科学、工业与交通、太空、陆军、海军、空军、战略与电子、军事学说），每页按分支排列，不再挤在一张图上。
- 每个军种选一种学说：陆军有闪电战、优势火力、大纵深作战等，海军有航母特混舰队、狼群战术、战列线决战，空军有制空优先、近距空中支援、战略轰炸。
- AI 会按威胁和预算决定陆海空的投入比例和兵种组合；领袖模式下你可以自己调整，或者直接选预设方案。

**博弈与意识形态**
- 国与国的互动被建模成 2×2 博弈：军备竞赛和贸易是囚徒困境，边境危机是懦夫博弈（双方拥核时变成恐怖平衡），同盟是猎鹿博弈，合并是协调博弈。各国按纳什均衡行动，多重均衡时按互信选择收益占优或风险占优；重复博弈里越有耐心越容易合作。「博弈」页记录每一局的收益矩阵。
- 11 种意识形态（部落、神权、君主、共和、自由民主、共产、法西斯、技术官僚、全球联邦、超人类、蜂巢）会跨越国界传播；民意倒向别的思想时会有选举、政变、革命和内战。被占领的城市会起义，霸权国会招来反制同盟。

**内容**
- 206 项科技（其中 94 项军事科技）、9 个时代、10 个科技分页；74 种兵种；52 项国策（含 6 条互斥的意识形态道路）
- 31 个成就挑战；世界会自动保存在浏览器里，下次打开继续

**安卓 APK**
- 安装包在 `dist/blue-planet.apk`（约 0.5 MB），支持 Android 5.0 及以上，完全离线运行，不申请任何权限。
- 安装：把 APK 发到手机上点开，按提示允许「安装未知来源应用」。华为、小米等手机的纯净模式或安全扫描可能会拦截或提示风险，选择「继续安装」即可，这是所有不经过应用商店的安装包都会遇到的。
- 横屏、竖屏都能玩，旋转屏幕不会丢进度。返回键会先关掉弹窗和面板，连按两次退出。切到后台时自动存档并暂停。
- 存档保存在应用自己的数据里。卸载应用会清掉存档；用同一个签名打包的新版本可以直接覆盖安装，存档保留（签名说明见 `android/README.md`）。

**在中国大陆游玩**
- `dist/blue-planet-offline.html` 是离线版：去掉了在大陆打不开的谷歌字体，代码转成了老版本手机浏览器也能运行的写法，打开时不访问任何网络。可以直接通过微信、QQ 发给别人。
- 在微信里收到后，建议点右上角选择「用浏览器打开」或「用其他应用打开」。微信内置浏览器能运行，但存档可能不会保留。
- 想放到网上：GitHub Pages 在大陆通常能打开但时快时慢，不保证稳定。国内云的静态托管（例如腾讯云 EdgeOne Pages）访问更稳，但要用自己的账号部署，绑定自己的域名时一般还需要 ICP 备案。

**开发**
- 源码按模块放在 `src/` 下（数据、模拟、战争、AI、地图绘制、城市、小人与战场、地球与太空视图、界面）。运行 `python3 src/build.py` 会按文件名顺序把它们拼成根目录下的单文件 `index.html`。
- `python3 tools/build_app.py --target web` 生成离线版 `dist/blue-planet-offline.html`，`--target android` 生成安卓用的页面；需要 Node.js，第一次运行会在 `tools/` 下安装 esbuild 和 acorn。加 `--verify` 会用无头浏览器加载并试玩一遍。
- `android/build.sh dist/blue-planet-android.html` 打包 APK（不用 Gradle，需要 JDK 和 Android SDK 的 platform 34、build-tools 34，详见 `android/README.md`）。
- `tools/shoot.js` 用无头浏览器截图并记录帧耗时，用来检查画面和性能。

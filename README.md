## 蓝星纪元

`index.html` 是一个可以独立运行的地球模拟：用浏览器直接打开即可，不需要安装任何东西，也不需要联网（联网时会加载更好看的字体）。

- 程序生成的星球：大陆、海洋、冰盖、山脉、森林、沙漠，以及煤炭、石油、铁矿、铀矿、稀土和渔场等自然资源
- 文明从公元前 3500 年的几个部落开始，自己定居、扩张、建城、打仗、分裂与合并
- 38 项科技、8 个时代：从农业、文字一路到蒸汽机、计算机、核聚变和星际航行
- 工业化后出现工厂和研究所，消耗资源、排放二氧化碳，引发升温、冰川融化和海平面上升
- 瘟疫、地震、火山、台风、干旱、陨石等随机事件，以及卫星、登月、轨道城市和星际方舟
- 五个图层（自然 / 政治 / 资源 / 人口 / 气候），点击城市或地块查看详情
- “上帝之手”：降下灵感、瘟疫、陨石，或在荒野中播种新文明
